# 社区页面蓝图

日期：2026-04-20

## 1. 目标

本蓝图用于把《社区改版设计稿》进一步落成页面级结构，明确：

- 哪些页面保留
- 哪些页面重组
- 每个页面承载什么用户任务
- 页面之间如何跳转
- 哪些模块应沉到通用组件

本蓝图默认基于当前 Expo Router 路由结构和现有社区底座演进，不另起一套全新导航。

## 2. 设计原则

- KISS：优先重组已有页面，不增加不必要的新路由层级
- YAGNI：不提前做完整关注关系、私信、直播、同城等复杂模块
- SOLID：每个页面只解决一个主要任务，页面内模块边界清晰

### 3.2 建议保留并重构的页面

- `/(tabs)/community`
- `/community/create`
- `/post/[id]`
- `/story-viewer`
- `/my-posts`
- `/search`

### 3.3 建议新增的页面

- `/community/question/[id]`
- `/community/tag/[tag]`

说明：

- `/community/question/[id]` 用于问题详情页，避免提问帖继续和普通内容帖完全共用同一详情结构
- `/community/tag/[tag]` 用于标签聚合页，支撑搜索和内容沉淀
- `/community/saved` 用于社区收藏内容集合，不和商品收藏混在一起

## 4. 一级导航蓝图

### 4.1 社区 Tab 顶部结构

社区主 Tab 顶部建议采用：

- 页面标题：社区
- 副标题：今天喝什么 · 怎么泡 · 值不值得买
- 右侧动作：
  - 搜索
  - 社区收藏
  - 发帖

### 4.2 一级标签

主 Tab 的一级标签建议调整为：

- 推荐
- 问答
- 冲泡

### 4.3 一级标签职责

#### 推荐

目标：

- 作为社区默认首页
- 混合承载种草、经验、问答、官方内容

核心价值：

- 帮用户快速发现值得看的内容
- 帮内容导向商品决策

#### 问答

目标：

- 聚焦“提出问题”和“解决问题”

核心价值：

- 沉淀可搜索的茶知识和购买决策问答

#### 冲泡

目标：

- 聚焦参数、器具、风味、复泡体验

核心价值：

- 沉淀结构化冲泡经验

## 5. 页面蓝图

## 5.1 页面 A：社区首页 `/(tabs)/community`

### 页面目标

- 统一承接社区进入流量
- 提供“看内容、看问答、看冲泡、去发帖”入口

### 页面结构

1. 顶部 Header

- 标题“社区”
- 搜索按钮
- 收藏按钮
- 发帖按钮

2. 一级标签区

- 推荐
- 问答
- 冲泡

3. Story Row

- 今日茶席
- 茶友速览
- 店员试喝

4. 主内容区

- 根据一级标签切换不同 feed

### 推荐 Feed 结构

推荐页建议按固定顺序混排：

1. 今日引导卡

- 例如“今天适合喝点什么？”
- CTA：发动态 / 看冲泡 / 去问答

2. 热门话题条

- 例如 `#春茶` `#龙井` `#办公室喝什么`

3. 混合推荐流

- 晒图种草卡
- 冲泡经验卡
- 问答卡
- 官方内容卡

4. 底部轻引导卡

- “还没找到想看的？去搜索”

### 问答 Feed 结构

1. 提问引导卡

- CTA：我要提问

2. 问题筛选条

- 最新
- 待解答
- 已解决
- 热门

3. 问题列表

- 标题
- 摘要
- 回答数
- 是否已解决
- 关联商品或标签

### 冲泡 Feed 结构

1. 冲泡记录引导卡

- CTA：记录一次冲泡

2. 筛选条

- 绿茶
- 乌龙
- 白茶
- 普洱
- 红茶

3. 冲泡经验列表

- 茶名
- 参数块
- 图片
- 心得
- 关联商品

### 页面状态

- Loading：骨架屏
- Empty：按频道展示不同空态
- Error：统一重试

## 5.2 页面 B：内容详情 `/post/[id]`

### 页面目标

- 承接晒图动态和冲泡记录的详情页
- 强化评论互动和商品转化

### 页面结构

1. 顶部作者区

- 头像
- 昵称
- 发布时间
- 位置
- 更多操作

2. 主内容区

- 若为晒图：图片 + 正文 + 场景标签
- 若为冲泡：茶名 + 参数块 + 图片 + 心得 + 风味标签

3. 商品挂卡区

- 相关茶品
- 相关茶具
- CTA：查看详情 / 加入购物车

4. 互动条

- 点赞
- 评论
- 收藏
- 分享

5. 相似内容区

- 同类茶内容
- 相近场景内容

6. 评论区

- 一级评论
- 评论回复
- 评论点赞

### 关键改动

- 继续保留现有 `/post/[id]` 路由，但只承接晒图动态和冲泡记录
- 评论区从扁平列表升级为“评论 + 回复”
- 增加“相关商品”和“相似内容”

## 5.3 页面 C：问题详情 `/community/question/[id]`

### 页面目标

- 承接提问帖的独立详情
- 把问题从普通内容中拆出来，形成知识沉淀结构

### 页面结构

1. 问题头部

- 问题标题
- 问题描述
- 标签
- 提问时间
- 是否已解决

2. 相关上下文

- 关联茶品
- 关联文章
- 相似问题

3. 最佳回答区

- 若已设置最佳回答，放在最上方

4. 回答列表

- 支持按“默认 / 最新”切换

5. 回答输入区

- 发表回答
- 引用商品 / 引用参数

### 关键改动

- 提问帖不再继续完全复用普通帖子详情页
- 问题页需要支持：
  - 最佳回答
  - 已解决状态
  - 相似问题

### 页面目标

### 页面结构

1. 内容类型选择

- 晒图动态

- 发起提问

2. 对应表单区

#### 晒图动态

- 文案
- 图片
- 位置
- 茶类标签
- 场景标签
- 关联商品

#### 冲泡记录

- 茶名

- 时间
- 投茶量
- 器具
- 图片
- 一句话感受
- 风味标签
- 关联商品

#### 发起提问

- 标题
- 描述
- 问题标签

### 页面结构

2. 搜索建议

- 热搜问题

### 关键改动

- 不再只查商品
- 搜索历史继续保留，但内容改成真正用户搜索词

### 关键改动

- 和商品收藏区分开
- 收藏不只是“以后再看”，而是“回访内容资产”

2. 子标签

3. 内容列表

### 关键改动

## 6. 页面跳转蓝图

### 6.1 推荐流

- 推荐卡 -> 内容详情 `/post/[id]`
- 问答卡 -> 问题详情 `/community/question/[id]`
- 标签 -> 标签页 `/community/tag/[tag]`
- 挂商品卡 -> 商品详情 `/product/[id]`

### 6.2 问答流

- 提问引导 -> `/community/create?type=question`
- 问题列表 -> `/community/question/[id]`
- 相似问题 -> 对应问题详情

### 6.3 冲泡流

- 冲泡引导 -> `/community/create?type=brewing`
- 冲泡卡 -> `/post/[id]`
- 挂商品卡 -> 商品详情

### 6.4 搜索流

- 搜索结果商品 -> 商品详情
- 搜索结果内容 -> 内容详情
- 搜索结果问答 -> 问题详情

## 11. 结论

页面蓝图的核心不是“加更多页面”，而是把当前社区改成三条清晰主路径：

- 发现值得看的内容
- 快速提出并解决问题
- 把冲泡经验沉淀成可复用资产

所有页面都要围绕这三条路径服务，并最终把内容价值自然导向商品决策，而不是把社区和商城继续分裂成两个平行模块。

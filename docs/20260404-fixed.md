     李记茶铺 App 有 4 个 P0 关键缺陷和约 10 个 P3 技术债务项。本计划按优先级修复所有问题。

     ---
     P0-1: 修复阿里一键登录双实现冲突

     问题：modules/ali-one-login/package.json 的 main 指向不存在的 index.ts，且 barrel 文件没有 default export，导致 7
     个 TS 错误。

     修复：在包根目录创建 modules/ali-one-login/index.ts：
     export { default, AliLoginErrorCodes } from './src/AliOneClickModule';
     export type { FusionLoginResult } from './src/AliOneClickModule';

     文件：
     - 新建：modules/ali-one-login/index.ts
     - 无需改动 src/modules/ali-one-login.ts 和 src/hooks/useOneClickLogin.ts

     ---
     P0-2: 修复被动登出状态残留

     问题：
     1. 被动 token 过期后不跳转登录页
     2. signOut() 不调用 resetCoupons()

     修复：
     - src/app/_layout.tsx：onAuthStateChange 中 session 变为 null 时，增加跳转 /login 的逻辑
     - src/stores/userStore.ts：signOut() 中增加 useCouponStore.getState().resetCoupons() 调用

     文件：
     - src/app/_layout.tsx (onAuthStateChange handler)
     - src/stores/userStore.ts (signOut 方法)

     ---
     P0-3: 修复商品详情冷启动问题

     问题：
     1. 深链直接打开时，products 为空数组，fetch 返回后可能闪现"未找到"
     2. router.back() 在空栈时崩溃

     修复：
     - 在 product/[id].tsx 中：当 bootstrapping 为 false 且 notFound 为 false 时，从 store 重新读取 product，若仍为
     undefined 则继续显示 loading 而非"未找到"
     - 将 router.back() 改为 router.canGoBack() ? router.back() : router.replace('/') 安全回退

     文件：
     - src/app/product/[id].tsx

     ---
     P0-4: 支付渠道环境变量警告

     问题：paymentConfig.ts 静默使用默认值，开发者无从知晓是否正确配置。

     修复：
     - 在 paymentConfig.ts 中增加 __DEV__ 模式下的 console.warn 提示未设置的支付环境变量
     - 确认 UI 已正确消费 getEnabledPaymentChannels()（经分析，UI 已正确接入，问题仅是缺少配置验证）

     文件：
     - src/lib/paymentConfig.ts

     文件：
     - src/components/profile/MenuList.tsx

     P3-2: 列表查询添加分页

     为所有全表查询增加 .limit() 防止大数据量时的性能问题。初始方案：为每个 fetch 函数增加 limit 参数（默认
     50），暂不实现无限滚动 UI（那属于功能增强）。

     文件：
     - src/stores/productStore.ts (fetchProducts, searchProducts)
     - src/stores/communityStore.ts (fetchStories, fetchPosts)
     - src/stores/articleStore.ts (fetchArticles, fetchSeasonalPicks)
     - src/stores/couponStore.ts (fetchPublicCoupons, fetchUserCoupons)
     - src/stores/orderStore.ts (fetchOrders)

     P3-3: 隐藏物流模拟开发按钮

     文件：
